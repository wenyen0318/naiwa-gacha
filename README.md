# 🐸 奶蛙抽卡樂園

一個結合「小遊戲」與「抽卡收集」的互動式網頁。玩家透過「接奶蛋」小遊戲賺取點數，再用點數抽取不同稀有度的奶蛙卡片，收集到圖鑑中。

🔗 線上遊玩：`https://你的帳號.github.io/naiwa-gacha/`（發布後請換成你的網址）

---

## 一、規格書

### 1. 專案目標
做出一個不需要伺服器、可直接放在 GitHub Pages 上執行的互動網頁，包含小遊戲、抽卡、圖鑑三大功能。

### 2. 核心流程
```
玩小遊戲 → 得到分數 → 分數轉成點數 → 花點數抽卡 → 卡片收進圖鑑
```

### 3. 功能規格

#### (1) 小遊戲：接奶蛋
| 項目 | 規格 |
|---|---|
| 遊戲時間 | 每局 30 秒 |
| 操作方式 | 方向鍵 ← →、A／D 鍵，或滑鼠、手指在畫面上拖曳 |
| 白奶蛋 🥚 | +10 分（出現機率 70%） |
| 金奶蛋 🌟 | +30 分（出現機率 10%） |
| 壞蛋 🤢 | −20 分（出現機率 20%），分數最低為 0 |
| 難度 | 時間越久，奶蛋掉得越快、出現得越頻繁 |
| 結算 | 本局分數 = 獲得點數，並記錄最高分 |

#### (2) 抽卡
| 項目 | 規格 |
|---|---|
| 花費 | 每抽一次 100 點，點數不足時按鈕無法按 |
| 抽卡方式 | 先依機率決定稀有度，再從該稀有度中隨機挑一張 |
| 動畫 | 卡片搖晃 → 翻面，稀有度越高光效越強 |
| 提示 | 第一次抽到顯示「NEW!」，重複抽到顯示第幾張 |

#### (3) 卡片與稀有度（共 12 張）
| 稀有度 | 機率 | 張數 | 卡片 |
|---|---|---|---|
| N 普通 | 60% | 5 | 原味、草莓、巧克力、抹茶、香蕉奶蛙 |
| R 稀有 | 30% | 4 | 珍奶、布丁、芋頭、優格奶蛙 |
| SR 超稀有 | 9% | 2 | 星空奶蛙、彩虹奶蛙 |
| SSR 傳說 | 1% | 1 | 黃金奶蛙王 |

#### (4) 圖鑑
- 顯示全部 12 張卡片；抽到的顯示圖案和名稱，沒抽到的顯示剪影和「？？？」
- 顯示收集進度條（已收集數 / 12）與每張卡的持有數量
- 提供「清除所有紀錄」按鈕

#### (5) 存檔
- 使用瀏覽器的 localStorage 保存點數、最高分、卡片收集紀錄
- 重新整理或關掉網頁後，紀錄仍會保留

### 4. 介面風格
- 粉嫩可愛風：奶油白、淡綠、粉紅色系，圓角按鈕
- 支援手機與電腦（響應式版面）

### 5. 技術規格
| 項目 | 使用技術 |
|---|---|
| 結構 | HTML |
| 樣式 | CSS（翻牌動畫、光效） |
| 程式 | JavaScript（Canvas 繪製小遊戲、SVG 繪製卡片） |
| 部署 | GitHub Pages |

## 三、與 AI 討論規格的過程
1. 提出想法：做一個小遊戲結合奶蛙抽卡，用遊戲賺點數來抽卡。
2. AI 提出初步規格草案（三個頁面、稀有度與機率表、存檔方式、技術選擇）。
3. 確認小遊戲：選擇「左右移動奶蛙接住掉下來的奶蛋」。
4. 確認稀有度：採用 N／R／SR／SSR 四種，機率 60／30／9／1%，共 12 張。
5. 確認風格：粉嫩可愛。
6. AI 補上細節（遊戲 30 秒、各種蛋的分數、抽卡 100 點），依規格生成程式並測試。
